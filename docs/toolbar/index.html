工具条 Toolbar

每个页面顶部都有一行 .toolbar，默认右对齐——这是沿用既有版式的结果： 主操作在右，视线从左往右读完标题正好落在动作上。

需要左侧有东西时，给第一个元素加 .toolbar-lead 把它顶到左边。

默认：右对齐
toolbar-lead：左一个 + 右两个（项目管理页）
toolbar-title：左侧统计 + 右侧动作（发布记录页）
共 4 个记录·1 个已过期
list-head：弹窗里的紧凑版（统计不吃 auto 外边距）

发布记录

.list-head .toolbar-title 把 margin-right:auto 改回 0 并换成 margin-left:9px —— 否则统计标题会和右侧按钮平分空白，标题与文字被拉开。

类名作用
.toolbarflex + gap: --gap-inline(8px) + justify-content: flex-end + margin-bottom: --gap-row(12px)
.toolbar-leadmargin-right: auto，把该元素顶到行首
.toolbar-titlemargin-right: auto + --fs-12 + --c-text-3；内部 <b> 反色加粗、.sep 分隔点、.dim 弱化

弹窗里的紧凑版：list-head

.list-head 是同一套思路的紧凑版，用在「列表类弹窗」的标题行：

<div class="list-head">
  <h3 class="modal-title">发布记录</h3>
  <span class="toolbar-title">共 <b>4</b> 个记录</span>
  <button class="btn is-ghost">清空记录</button>
</div>
.list-head { display: flex; align-items: center; margin-bottom: var(--px-12); }
.list-head .modal-title { margin-bottom: 0; }
.list-head .btn { margin-left: auto; }

/* 关键的一行覆盖 */
.list-head .toolbar-title { margin-right: 0; margin-left: var(--px-9); }

最后那行是必须的：.toolbar-title 自带 margin-right: auto，在页面工具条里它靠这个吃掉空白、 把按钮推到最右；但在 list-head 里右侧按钮已经用 margin-left: auto 占据了空白， 两个 auto 会平分剩余空间——结果是「发布记录」和「共 4 个记录」之间被拉开一道大缝。 所以弹窗里要把它改回 margin-right: 0。
