开关 Switch

关于页要一个「有新版本时自动检查」的布尔偏好。全站此前没有任何「开 / 关」控件， 复选框（input[type=checkbox]）在两套主题下的原生外观差异太大，索性自己画一个。

两态：关 / 开
关开

结构

<button class="switch is-on" role="switch" aria-checked="true" title="自动检查更新"></button>
类名 / 属性作用
.switch轨道本体：--switch-w × --switch-h、--r-pill 药丸形、--c-switch-off 底
.switch.is-on底 → --c-switch-on，滑钮右移
.switch::after滑钮：--switch-knob 见方 + --r-full 正圆 + --c-switch-knob 底
role="switch" + aria-checked让读屏软件知道这是开关而非普通按钮

元素用 <button> 而不是 <div>：它天然可聚焦、可键盘触发，Enter / Space 的语义 与点击一致，不用自己补键盘处理。焦点环走全站统一的 .switch:focus-visible （--c-ring + --px-2 外偏移）。

位移是用算式算的，不是写死的

.switch::after        { top: var(--px-2); left: var(--px-2); }   /* 两侧各留 2px */
.switch.is-on::after  { transform: translateX(calc(var(--switch-w) - var(--switch-knob) - var(--px-4))); }

--px-4 就是两侧内边距之和（2px × 2）。这样把 --switch-w / --switch-knob 任意调大调小，滑钮都恰好停在轨道右内侧，不会露缝也不会越界。 位移用 transform 而非改 left：不触发重排，且能吃到 --dur-fast 的过渡。

滑钮是纯白，轨道才换色

/* tokens.css */
:root                  { --c-switch-knob: var(--w0); }        /* #ffffff —— 两套主题共用 */
[data-theme="light"]   { --c-switch-off: var(--bk12); --c-switch-on: var(--lt-primary); }

这是全站唯一一处「第 2 层语义令牌在浅色下不重绑」（--c-switch-knob 只声明在 :root，浅色段里没有它）。原因是这一条没法机械镜像：

深色浅色
关12% 白（灰）12% 黑（浅灰）
开24% 白（更亮）近黑实底 #161616

深色的「开」是「比关更亮一阶」，浅色的「开」如果照这个规律走就是「比关更深的灰」—— 在浅灰底上完全立不住。所以浅色的开态直接跳到近黑，跟主按钮同一个色值（--lt-primary）， 形成「深色靠亮度、浅色靠对比」的同一套逻辑。滑钮若跟着主题变深，在近黑轨道上就看不见了， 所以它两套主题都是纯白。
