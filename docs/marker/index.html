类名效果
.dot7×7 圆形，--c-text-3（未运行，与元信息同色）
.dot.is-on--c-ok 绿 + box-shadow: 0 0 6px var(--c-ok-glow) 辉光

.tag —— 来源标记

<span class="tag">pc</span>

标出这个项目是从哪个脚手架模板建的（pc / mobile）。--fs-10 + --hairline 描边 + --r-5，比 .port-chip 更轻——它只是背景信息，不需要被主动读取。

.pl-badge —— 发布状态徽标

四态由 publish.js 的 pubBadgeState() 推导：

function pubBadgeState(r, now) {
  if (!r.expiresAt) return { text: "长期有效", variant: "perm" };
  const left = r.expiresAt - now;
  if (left <= 0)              return { text: "已过期", variant: "dead" };
  if (left < 10 * 60000)      return { text: "剩余 " + Math.ceil(left / 60000) + " 分钟", variant: "warn" };
  return { text: "剩余 " + Math.round(left / 60000) + " 分钟", variant: "" };
}
类名效果触发条件
.pl-badge--c-surface-3 底 + --c-text-2 字剩余 ≥ 10 分钟
.pl-badge.is-warn字色 → --c-warn-strong（暖黄）剩余 < 10 分钟
.pl-badge.is-dead字色 → --c-text-3（弱化）已过期
.pl-badge.is-perm底 → --c-surface-6 + 字 → --c-text（提亮）无 expiresAt

注意 10 分钟这个阈值和 warn 变体的存在意义：临时账号 60 分钟不认领就会被 Cloudflare 连同部署一起删除，所以临近失效必须变脸提醒。这个阈值来自 expiresAt 字段——它是从 wrangler 输出里解析 Claim within: N minutes 得到的真实剩余时间，不是硬编码的 60 分钟 （复用旧临时账号时窗口可能只剩十几分钟，写死会骗人）。
