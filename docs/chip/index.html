标签 Chip

可点选的小标签，用于构建产物目录这类「多选一」的轻量选择。

标签 Chip

发布时要让用户选构建产物目录（dist / build / out），这些名字很短、候选项通常 1–3 个， 用下拉框太重、用按钮太重、用单选框更重。chips 正好。

chip-row：默认 / hover / 选中
chip-bar：chips 占满左侧，动作按钮靠右

选中态（.is-on）用「更亮的底 + 反白字」表达，不加描边也不上彩色。

/**
 * Chip —— 可点选标签
 * 结构来自 UI.chipList()：`.chip`（可选 `is-on`）内可带 `<small>` 附注。
 * 用于发布时选择构建产物目录、以及任何「多选一」的轻量场景。
 */

export function Demo() {
  return (
    <div className="pb-stack">
      <div>
        <span className="pb-spec">chip-row：默认 / hover / 选中</span>
        <div className="chip-row">
          <button className="chip">dist</button>
          <button className="chip pb-show-hover">build</button>
          <button className="chip is-on">out</button>
          <button className="chip">public<small>12 文件</small></button>
        </div>
      </div>

      <div>
        <span className="pb-spec">chip-bar：chips 占满左侧，动作按钮靠右</span>
        <div className="chip-bar">
          <div className="chip-row">
            <button className="chip is-on">dist<small>68 文件 · 3.4 MB</small></button>
            <button className="chip">build<small>12 文件 · 0.7 MB</small></button>
          </div>
          <button className="btn is-ghost">手动指定</button>
        </div>
      </div>

      <p className="hint" style={{ marginBottom: 0 }}>
        选中态（<code>.is-on</code>）用「更亮的底 + 反白字」表达，不加描边也不上彩色。
      </p>
    </div>
  );
}

结构

渲染工厂 UI.chipList(items) 只产出 chips 内容，不含容器（容器写在 index.html 里）：

UI.chipList([
  { text: "dist",  sub: "68 文件 · 3.4 MB", on: true, act: "dist-pick", data: { v: "/…/dist" } },
  { text: "build", sub: "12 文件 · 0.7 MB",            act: "dist-pick", data: { v: "/…/build" } },
])
// → <button class="chip is-on" data-act="dist-pick" data-v="/…/dist">dist<small>68 文件 · 3.4 MB</small></button>
//   <button class="chip" data-act="dist-pick" data-v="/…/build">build<small>12 文件 · 0.7 MB</small></button>
<div class="chip-bar">
  <div class="chip-row" id="distChips"></div>
  <button class="btn is-ghost" data-act="dist-probe">重新探测</button>
</div>
类名作用
.chip-rowflex + wrap + gap: 6px
.chip药丸形（--r-pill）+ --fs-11 字 + --c-surface-3 底
.chip.is-on选中：--c-accent-bg 底 + --c-text-inv 反白
.chip small附注文案，opacity: .6 + 左侧 3px 间距
.chip-barchips 在左（flex:1）、动作按钮在右（flex:none）

唯一显式声明字体族的组件

.chip { font-family: inherit; }

全文件只有这一处写 font-family。因为 .chip 是 <button>，而原生控件的字体族在 base.css 里刻意不覆写（依赖 UA 默认）——但 chip 是「文字为主的胶囊」，用 UA 按钮字体 会显得比旁边的正文粗一号，所以要显式继承。
