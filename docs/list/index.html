类名作用
.pl-listmax-height: var(--list-max-h) = 390px + overflow-y: auto；负外边距 -4px + padding 4px 让滚动条不贴边
.pl-list.is-page解除限高、去掉负边距，改成 grid auto-fill minmax(340px, 1fr) 多列
.pl-item--c-surface-1 底 + --hairline 描边 + --r-10；margin-bottom: 8px，:last-child 归零
.pl-item.is-deadopacity: .6 —— 过期记录整体降透明度
.pl-top一行：pl-proj + pl-badge（徽标靠 margin-left:auto 沉到右侧）
.pl-proj--fs-13 + 600 字重 + 单行省略号
.pl-url--ff-mono 等宽字体 + --fs-11 + word-break: break-all（长 URL 必须能断）
.pl-meta时间 · 相对时间 · 目录，--fs-11 + --c-text-3 + 单行省略
.pl-ops操作行；.pl-ops .btn 覆写成更小尺寸（3px 10px + --fs-11）

「复制链接」是实底，其余是 ghost

const ops = [
  UI.btn("复制链接", { act: "pub-copy", data: { v: r.url } }),        // 主操作 → 实底
  UI.btn("打开", { variant: "ghost", act: "pub-open", data: { v: r.url } }),
];
if (r.claimUrl) {
  ops.push(UI.btn(dead ? "认领（已过期）" : "认领", {
    variant: "ghost", act: "pub-open", data: { v: r.claimUrl },
    title: "窗口期内登录 Cloudflare 可把临时账号转成你自己的",
  }));
}
ops.push(UI.btn("移除", {
  variant: "ghost", act: "pub-remove", data: { v: r.id },
  title: "只删本地记录，不影响 Cloudflare 上的部署",
}));
  • 每条记录只有一个实底按钮（复制链接）——列表里按钮很多，全都实底会糊成一片；
  • 有 claimUrl 才渲染「认领」：永久记录（expiresAt 为 null）没有认领窗口， 渲染出来只会让人困惑；
  • 「移除」的 tooltip 明说「只删本地记录」——这个操作名容易让人以为会删掉线上部署。

空态

if (!publishes.length) {

  box.firstChild.classList.add("pl-empty");
  box.firstChild.classList.remove("empty-state");
  return;
}

这里生成后再换类名：.empty-state 的上下内边距是 40px，对列表容器太松， 换成 .pl-empty（34px 且 --fs-12）更贴合。
