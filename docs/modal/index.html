外壳

类名作用
.overlayposition: fixed; inset: 0 + --c-scrim 遮罩；display: none
.overlay.is-opendisplay: flex + 居中 —— 唯一控制显隐的开关
.modal--c-modal 底（比应用底亮一档）+ --hairline 描边 + --r-14 + 20px 内边距
.modal.is-wide宽 560px（列表型 / 多字段表单）
.modal.is-publish宽 470px（发布弹窗，介于两者之间）
.modal-title--fs-14 + margin-bottom: 14px
.modal-footflex + flex-end + gap: 8px + margin-top: 16px
.modal-status在 foot 里 margin-right: auto —— 左侧状态文字、右侧按钮

显隐只靠 .is-open 类，没有内联 style.display。切换走 core.js 的 openModal(id) / closeModal(id)，两者都只是 classList.toggle。

三档宽度

--modal-w:         440px;   /* 默认：编辑 / 手动添加 / 删除确认 */
--modal-w-publish: 470px;   /* 发布（比默认多一列 chip-bar） */
--modal-w-wide:    560px;   /* 列表型：发布记录 / 从模板新建 */

宽度是内容驱动的，不是随手定的：编辑弹窗有三个字段 + 一行两列，440px 刚好； 发布弹窗多了 chips 行，470px；列表型要放下 URL（等宽字体，长）与四个操作按钮，560px。

类名作用
.fieldmargin-bottom: 10px；.field .input 自动 width: 100%
.field-labeldisplay: block + --fs-11 + --c-text-2 + margin-bottom: 4px
.field-rowflex + gap: 10px，两个 .field 各 flex: 1; min-width: 0
.field.is-slimflex: none; width: var(--field-slim-w) = 110px
.field-static只读展示值（如发布弹窗里的项目名），--fs-13 + --c-text
.field-hint字段下方的校验/说明行，--fs-11 + --c-text-3；.is-bad 红 / .is-good 绿
.hint弹窗级提示行（不是字段级），min-height: 17px 防止出现/消失时弹窗跳动

min-height: 17px 这个细节值得注意：.hint 是空的时候也有高度， 这样提示文字出现/消失时弹窗高度不变，不会跳。

交互约定

  • 点遮罩不关弹窗。 .overlay 上没有绑点击关闭：这几个弹窗都承载表单或不可逆操作， 误点遮罩丢掉填了一半的内容代价太大；
  • Esc 关删除确认。 main.js 里给 Delete 弹窗单独绑了 Esc；其余弹窗只能显式点按钮关；
  • 忙碌态不关窗。 「从模板新建」在克隆过程中 closeTemplate() 会直接 return， 按钮变禁用、状态行转圈，失败时把错误落在弹窗里而不是关掉再 toast。
