空态 Empty / Void

两种「没有内容」：有容器但空（empty-state），整页还没做（void-state）。

空态 Empty / Void

空态分两种，别混用：

  • .empty-state —— 容器在、内容为空。项目网格没项目、雷达没监听端口、发布记录为空。
  • .void-state —— 整页功能还没做（模板库、设置页的占位）。

区分点在于：前者要引导用户去做点什么（右上角有个按钮），后者要诚实说明这里还没有。

.empty-state

.empty-state {
  color: var(--c-text-3);
  text-align: center;
  padding: var(--px-40) 0;
}
.empty-state.is-compact { padding: var(--px-20) 0; }
.table td.empty-state   { padding: var(--px-40) 0; }   /* 抢回被 td 压扁的内边距 */
修饰用途
.span-all作为栅格子项时通栏（grid-column: 1 / -1）。用在 .card-grid 里
.is-compact上下内边距减半（40px → 20px），用在「读取中…」这种临时态

三种用法：

// ① 项目网格：通栏
grid.innerHTML = UI.empty("还没有项目，点右上角「从模板新建」或「手动添加」", { span: true });

// ② 临时加载态：紧凑
$("tStatus").innerHTML = UI.spinner("正在克隆模板…");

// ③ 表格单元格：直接写在 td 上（radar.js）
'<tr><td colspan="4" class="empty-state">当前没有监听中的端口</td></tr>'

第三种要注意：.empty-state 直接作为 <td> 的类，而不是里面再包一层 div —— 所以需要 .table td.empty-state 这条覆盖来对抗 .table td 的 8px 内边距。

.void-state

<div class="void-state">
  <div class="void-title">模板库</div>
  <div class="void-desc">
    内置脚手架模板的浏览与维护还没做。<br />
    现在可以先从「项目管理」页的「＋ 从模板新建」直接用它们。
  </div>
  <button class="btn is-primary">去从模板新建</button>
</div>
类名作用
.void-state--c-surface-1 底 + --hairline 描边 + --r-12 + 46px 20px 内边距 + 居中
.void-title--fs-13 + 600 字重
.void-desc--fs-12 + --c-text-3 + line-height: 1.7；内部用 <br> 断行控制节奏
.void-state .btnmargin-top: 16px

每个 void 页都必须给一个出口按钮。 模板库占位页上的「去从模板新建」把用户直接送到 真正能完成这件事的地方——占位页的价值不是说明「没做」，而是把需求接住。
