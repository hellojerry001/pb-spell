.spinner —— 唯一带关键帧的组件

<span class="spinner"></span>正在克隆模板… 12s
.spinner {
  display: inline-block;
  width: var(--spinner);           /* 10px */
  height: var(--spinner);
  margin-right: var(--px-7);
  border: var(--px-1-5) solid var(--c-spinner-track);   /* 1.5px 灰环 */
  border-top-color: var(--c-spinner-head);              /* 只有顶部提亮 */
  border-radius: var(--r-full);
  animation: spin var(--dur-spin) linear infinite;      /* .8s 匀速 */
}

三处细节：1.5px 边框（1px 太小看不见、2px 显笨）、只提亮 top（整环提亮就没有转动感）、 纯 CSS（不用图片、不用 SVG 动画）。@keyframes spin 定义在 base.css。

.pub-status —— 发布结果三态

<div id="pubStatus" class="pub-status"></div>
// 加载中
$("pubStatus").innerHTML = '<div class="pub-loading">' + UI.spinner("正在上传到 Cloudflare…") + "</div>";

// 成功
$("pubStatus").innerHTML = '<div class="pub-ok">✓ 发布成功 · ' + esc(url) + "</div>";

// 失败（wrangler 的原始输出带 ANSI 颜色码，已经过 strip_ansi）
$("pubStatus").innerHTML = '<div class="pub-err">发布失败：\n' + esc(msg) + "</div>";
类名效果
.pub-status容器，margin: 4px 0 2px，--fs-12
.pub-loading--c-text-2
.pub-ok--c-ok-strong（明亮绿）+ margin-bottom: 6px
.pub-err--c-danger + white-space: pre-wrap + word-break: break-word

.pub-err 的 pre-wrap 是为了保住 wrangler 输出里的换行——错误信息常常是多行的， 压成一行会丢掉结构。word-break: break-word 则保证超长路径/URL 不会撑破弹窗。

.pub-count 与 .pub-tip

<div class="pub-count">已发布 4 次，其中 1 条已过期</div>
<div class="pub-tip">部署到 Cloudflare 边缘网络：匿名临时公开链接，<b>默认 60 分钟自动失效</b>…</div>

.pub-tip 是弹窗底部的限制说明，--fs-11 + --c-text-3 + line-height: 1.6。 里面用 <b> 强调关键约束（「默认 60 分钟自动失效」）——这类说明必须有人真的读， 所以不能做成一片均匀的灰字。

.toast —— 全局提示

<div class="toast" id="toast"></div>
function toast(msg) {
  const el = $("toast");
  el.textContent = msg;
  el.classList.add("is-open");
  clearTimeout(el._t);
  el._t = setTimeout(() => el.classList.remove("is-open"), 2600);
}
类名效果
.toastposition: fixed 底部居中；--c-surface-5 底 + backdrop-filter: blur(8px) + --r-10
.toast.is-opendisplay: block（默认 display: none）

两个细节：

  • clearTimeout + 重新计时。连续操作时（比如连点几次刷新）不会出现「第一条 toast 的 计时器把第二条提前关掉」；
  • 毛玻璃而不是实底。Toast 浮在内容之上，实底会显得像一块补丁；blur(8px) 让底下内容 透出来一点，视觉上「浮」在界面之上。这也是唯一使用 backdrop-filter 的地方。
