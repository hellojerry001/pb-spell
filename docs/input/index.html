默认 · 聚焦

聚焦只改边框颜色（--c-border-focus），不加外发光、不位移，避免界面跳动。

input-row：输入框 + 尾部按钮

左侧输入框 flex:1; min-width:0 —— 长路径先在框内滚动，不会把按钮挤出容器。

search：吃掉剩余宽度，按钮靠右

export function Demo() {
  return (

          <input
            className="input pb-show-focus"
            defaultValue="https://github.com/hellojerry001/Port-build"
            style={{ width: 300 }}
          />
        </div>
        <p className="hint" style={{ marginTop: 10, marginBottom: 0 }}>
          聚焦只改边框颜色（<code>--c-border-focus</code>），不加外发光、不位移，避免界面跳动。
        </p>
      </div>

      <div>
        <span className="pb-spec">input-row：输入框 + 尾部按钮</span>
        <div className="input-row" style={{ maxWidth: 460 }}>
          <input
            className="input"
            defaultValue="/Users/jerry/WorkBuddy/2026-09-08-09-29-54/customer-volume-analysis"
            readOnly
          />
          <button className="btn is-ghost">选择文件夹</button>

类名

类名作用
.input输入框本体。--c-fill-field 底 + --c-border-field 描边（浅色下描边透明，边界由填充色承担）+ --r-8 圆角
.input:focus边框色 → --c-border-focus（不套焦点环）
.input-row并排容器：.input 吃 flex:1; min-width:0，.btn 固定不缩
.searchflex: 1，放在 .toolbar 里吃掉剩余宽度
.input {
  background: var(--c-fill-field);
  border: var(--hairline) solid var(--c-border-field);
  color: var(--c-text);
  border-radius: var(--r-8);
  padding: var(--px-6) var(--px-10);
  font-size: var(--fs-12);
}

.input:focus { border-color: var(--c-border-focus); }

.input-row { display: flex; gap: var(--px-6); }
.input-row .input { flex: 1; min-width: 0; }   /* min-width:0 是关键 */
.input-row .btn   { flex: none; }

两个容易忽略的点

聚焦不加焦点环。 按钮用 :focus-visible 加灰阶描边，但输入框不加——浏览器对文本框 在鼠标点击时也会命中 :focus-visible，套上环之后每次点输入框都会多出一圈描边，很吵。 输入框的聚焦反馈只靠边框变色。

min-width: 0 不能省。 flex 子项默认 min-width: auto，长路径输入框会把按钮挤出容器 （因为输入框内容的固有宽度撑住了它）。加上 min-width: 0 之后，长内容先在框内滚动。

反例（去掉 min-width:0）：

/Users/jerry/WorkBuddy/2026-09-08-09-29-54/customer-volume-analysis  [选择文件夹]
                                                          ↑ 按钮被顶出可视区
