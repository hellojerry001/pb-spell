开始

概览
PortButler 的界面层是怎么组织的：四层样式、三层令牌、渲染工厂与事件委托。
设计令牌
216 个令牌的三层结构、两套主题，以及为什么界面不该攒灰值。
主题
三态切换、初始加载不闪烁的原因，以及浅色下不能机械镜像的两处。

基础

按钮 Button
四种变体（默认 / 幽灵 / 主操作 / 危险）、禁用态与计数角标。
输入框 Input
输入框、聚焦态、输入框 + 尾部按钮的并排布局、搜索框。
工具条 Toolbar
页面顶部的按钮行，以及弹窗里紧凑版的 list-head。
标签 Chip
可点选的小标签，用于构建产物目录这类「多选一」的轻量选择。
标记 Marker
状态点、端口标签、来源标记、发布状态徽标 —— 四个「一小块信息」级别的原子件。
开关 Switch
纯 CSS 开关：滑钮是一个 ::after，开与关只做 transform 位移。

数据展示

卡片 Card
项目卡片：状态点 + 图标缩略图 + 名称 + 来源标记 + 端口，以及底部一排操作。
表格 Table
端口雷达的表格：弱化表头、加粗端口、固定宽度操作列、整行 hover。
记录列表 List
发布记录列表：弹窗限高滚动版与页面多列版共用同一套 pl-item。
模板卡 TplCard
从模板新建时选择脚手架的卡片：两列网格、选中态、Node 版本提示。

反馈

空态 Empty / Void
两种「没有内容」：有容器但空（empty-state），整页还没做（void-state）。
反馈 Feedback
加载转圈、发布结果三态、计数说明、全局 toast。
打包日志 BuildLog
Mac 项目打 DMG 时的进度与输出 —— 状态行负责「还活着」，日志块负责「为什么」。

弹窗

弹窗 Modal
遮罩 + 弹窗外壳，三档宽度（440 / 470 / 560），表单型与列表型两种内容。
危险确认 DelBox
删除项目的二次确认：路径展示、可选复选框、失败不关窗。

导航

侧栏导航 Rail
64px 宽的图标导航栏：选中药丸、自绘悬浮名称气泡、底部项撑开。
分类页签 Tabs
项目页顶部的 Web / Mac 分栏 —— 为什么两类项目不该混在一张列表里。
